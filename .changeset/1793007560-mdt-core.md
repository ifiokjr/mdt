# Consumer files are written atomically and update watch logs to stderr

write_updates now writes each updated file to a hidden sibling temporary file and renames it over the original, so an interrupted update can never leave a truncated consumer file. Original file permissions are preserved, new files are still created, and symlinked destinations write through to the resolved file. update --watch status messages moved from stdout to stderr, matching check --watch, so piped update output stays machine-readable.
