# Migrate release tooling from knope to monochange

The publish workflow now runs on a v* tag push: it builds and attests release binaries, publishes crates and npm packages, and publishes the draft release. Release lockfile handling moved to monochange ecosystem lockfile_commands. TypeScript tooling upgraded (tsgo 0.7, typescript 7, oxlint 1.78, oxfmt 0.63) and dprint now formats TS via the oxc plugin.
